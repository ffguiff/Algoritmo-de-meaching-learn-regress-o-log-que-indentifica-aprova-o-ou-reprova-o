# Algoritmo-de-meaching-learn-regress-o-log-que-indentifica-aprova-o-ou-reprova-o
Usando regressão logísca conseguimos atraves do treinamento e teste de metricas para verificar a acertividade da analise(acuracia, f1 score, precisão, recall), pode se definir se uma pessoa foi aprovada ou reprovada, com base nos dados ja existente de outra pessoa que passaram pelo mesmo processo.
